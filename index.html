🛝 놀이터 등록

⚠️ 공공 야외 놀이터만 등록이 가능합니다. 유료 시설 및 실내 놀이터는 안내 없이 삭제될 수 있어요.

초상권 보호를 위해 사람의 얼굴이 찍힌 사진은 업로드하지 않도록 주의해주세요.

놀이터의 특징이나 이용하면서 기억에 남는 점을 자유롭게 알려주세요!

🔒 비밀번호 확인

등록 시 설정한 숫자 4자리를 입력해주세요.

비밀번호가 맞지 않아요.
📍 지도를 클릭해서 위치를 선택하세요

📖 이용 방법

🛝 놀이터 등록하기

  1. 화면 왼쪽 하단의 + 버튼을 눌러요
  2. 주소를 검색하거나 지도에서 위치를 직접 선택해요
  3. 놀이터 이름, 특징, 사진을 입력해요
  4. 수정·삭제에 쓸 숫자 4자리 비밀번호를 설정해요
  5. 등록하기 버튼을 누르면 지도에 바로 표시돼요!

🔍 놀이터 찾기

  • 지도를 직접 탐색하거나 검색창을 이용해요
  • 지도 핀을 클릭하면 상세 정보를 볼 수 있어요
  • 모바일에서는 우측 상단 🔍 버튼으로 검색창을 열어요

✏️ 수정 · 🗑️ 삭제

  • 등록 시 설정한 비밀번호 4자리가 필요해요
  • 게시글 하단의 수정 / 삭제 버튼을 눌러요
  • 비밀번호를 잊어버렸다면 다시 등록해주세요 🙏

💬 댓글

  • 놀이터 상세 페이지 하단에서 댓글을 남길 수 있어요
  • 닉네임 없이도 익명으로 작성 가능해요
